# 6회차 · 내 앱 확장 프롬프트

4회차 build-prompts.md의 7개 앱을 바탕으로 만든 선택 실습입니다. 6회차 로그인·데이터 권한 실습 후 사용하거나 이후 개인 실습으로 이어가세요. 각 앱 제목을 펼쳐 전체 프롬프트를 복사할 수 있습니다.

내 앱 프로젝트에서 실행하세요. 기본은 1단계만 구현합니다. 다음 기능은 결과를 확인한 뒤 “2단계를 이어서 구현해줘”처럼 요청하세요. 외부 연동은 별도 준비와 시간이 필요할 수 있습니다.

Google Calendar의 파일 가져오기와 API 연동은 다릅니다. API 연결에는 Google 로그인과 별도로 OAuth 권한 동의가 필요합니다. 참고: [Google Calendar 일정 생성](https://developers.google.com/workspace/calendar/api/guides/create-events), [최소 권한 범위 선택](https://developers.google.com/workspace/calendar/api/auth).

## 1. 김기택 · 안녕 옥천 · 행사 찜과 내 관심 행사 목록

```text
내가 4회차에 만든 "안녕 옥천" 앱을 확장해줘.

작업 조건:
- 현재 프로젝트와 README, 설치된 버전의 공식 안내, 구현된 기능을 먼저 확인해줘. 새 앱을 만들지 말고 기존 앱에 추가해줘.
- 아래 후보 중 기본은 1단계 하나만 구현해줘. 내가 다른 단계를 명시하면 선택한 단계와 필요한 선행 작업만 진행해줘. 이미 구현되어 있으면 동작을 확인하고 빠진 부분만 보완해줘.
- 기존 데이터·업로드·원고와 핵심 기능을 보존해줘. DB 변경은 백업과 추가 마이그레이션으로 진행하고 초기화하지 마.
- 웹 앱의 로그인/Neon이 연결되어 있으면 서버가 확인한 사용자 ID로 소유권을 검사해줘. 아직 준비되지 않았다면 필요한 선행 설정을 안내하고 데모와 실제 연동을 구분해줘.
- 외부 서비스가 필요한 단계는 현재 공식 문서로 계정·권한·비용·설정을 확인해줘. 비밀값은 채팅·코드·로그에 적지 말고, 실제 계정 설정이 필요한 부분은 내가 따라 할 순서로 알려줘.
- 저장 중·빈 상태·실패·재시도를 표시하고 실패해도 기존 입력을 유지해줘.
- 구현 뒤 선택한 단계의 완료 기준과 기존 핵심 흐름을 확인하고, 변경 내용·실행 방법·실제 확인한 결과·미검증 항목을 알려줘.

1단계 · 먼저 추천: 행사 찜
- 로그인한 사용자가 공개 행사 상세에서 찜/해제를 하고 '내 관심 행사'에서 모아보게 해줘.
- 같은 사용자가 같은 행사를 중복 저장하지 못하게 하고 다른 사용자의 찜은 보이지 않게 해줘.
- 취소되거나 일정이 바뀐 행사는 내 목록에서도 현재 상태와 최종 확인일을 보여줘.
완료 확인: 계정 A로 찜 → 새로고침 후 유지 → 계정 B에는 안 보임 → 찜 해제. 기존 검색과 관리자 행사 수정도 확인해줘.

2단계 · 다음 확장: 행사 일정 .ics 내보내기
행사 상세에 캘린더 파일 다운로드를 추가해줘. 제목·시작/종료·장소·원문 링크와 안정적인 UID를 포함하고 한국 시간과 여러 날 행사를 확인해줘. 내려받은 일정은 행사 수정·취소를 자동 반영하지 않는다고 안내해줘.

3단계 · 더 확장: 관심 분야별 모아보기
사용자가 선택한 공연/교육/클래스 분야와 기간으로 공개 행사를 필터링해줘. 실제 출처에 없는 행사를 생성하지 마.
```

```text
- 일정 상세에 .ics 다운로드를 추가해 Google Calendar 등에서 가져올 수 있게 해줘. 직접 API 연동과 구분해 표시해줘.

2단계 · 다음 확장: Google Calendar API로 보내기

사용자가 연결할 Google 계정과 대상 캘린더를 선택하고 전송 내용을 확인한 뒤 일정 하나를 보내게 해줘. 서버에서 토큰을 안전하게 보관하고 브라우저·로그에 노출하지 마. 사용자·앱 일정·외부 event ID 매핑과 중복 전송 방지를 구현해줘.
이번 단계는 앱에서 Google로 보내는 단방향 전송이야. Google에서 변경한 내용을 자동으로 가져온다고 표현하지 마. 앱 수정/삭제를 Google에도 반영할지는 사용자가 따로 선택하게 해줘.
권한 거절·토큰 만료·연결 해제·재시도를 처리하고 실패해도 원래 일정은 유지해줘. 실제 계정 연결 전에는 데모라고 표시하고 실제 연결 완료로 표현하지 마.

3단계 · 더 확장: 반복 업무와 마감 체크리스트
매주/매월 반복 규칙과 일정별 체크리스트를 추가해줘. 이번 일정만 수정할지 이후 일정도 수정할지 구분하고 월말·공휴일 처리 규칙부터 정해줘.
```

## 4. 이봄길민들레 · 뚱냥이 방지 사료 측정앱 · 급식 기록과 체중 추이 함께 보기

```text
작업 조건:

- 날짜별 체중 kg과 메모를 저장하고 최근 7일/30일의 급식 기록과 나란히 보여줘.
```
